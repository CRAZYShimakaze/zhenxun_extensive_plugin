# zenlesszonezero_recommend

zhenxun_bot 绝区零攻略插件，展示角色攻略、角色养成材料和音擎图鉴。

## 使用

- `安比攻略`
- `安比素材` / `安比材料`
- `硫磺石图鉴` / `硫磺石音擎`
- `更新绝区零推荐`（仅超级用户可用）
- `检查绝区零插件更新`（仅超级用户可用）

资源来自 `CRAZYShimakaze.github.io/zzz`。插件启动时获取资源索引和角色别名，查询时按需下载图片；每天随机时间执行一次增量更新和插件版本检查。
